---
title: "Podman"
description: "Run the Docker Compose stack with Podman."
---

<Note>
  Not tested yet. The commands use the same files as
  [Docker Compose](/deployment/dockercompose); please report what you find.
</Note>

Requires Podman 4.7 or later, for `podman compose`.

```bash
git clone https://github.com/apowerb/apowerb-hosting.git
cd apowerb-hosting
cp .env.example .env
./scripts/generate-secrets.sh
podman compose -f docker-compose/docker-compose.yml --env-file .env up -d
```

Set the first administrator first, as in
[Docker Compose, step 2](/deployment/dockercompose#2-name-the-first-administrator),
then open [http://localhost:3000](http://localhost:3000).

A single `podman run apowerb/apowerb` is not enough: the API needs its
database and its encryption key, which the compose file provides.
